# 🎓 AI 知识复习小程序

一个现代化的人工智能基础知识复习助手，包含325道精选题目。

## 📋 功能特性

### 1. **练习模式** 📝
- 逐题练习，实时反馈
- 显示答案和解析
- 进度追踪和统计
- 准确率计算
- 支持上一题/下一题导航
- 随机出题功能

### 2. **浏览模式** 📚
- 搜索题目和答案
- 按题型筛选（单选、多选、填空、判断、简答）
- 快速跳转到任意题目
- 实时搜索结果

### 3. **统计模式** 📊
- 总体学习统计
- 题型分布展示
- 学习时长记录
- 数据导出功能
- 进度重置选项

## 🚀 快速开始

### 方法一：直接打开
1. 在浏览器中打开 `index.html` 文件
2. 开始复习！

### 方法二：使用本地服务器（推荐）
```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Python 2
python -m SimpleHTTPServer 8000

# 或使用 Node.js
npx http-server
```

然后访问 `http://localhost:8000`

## 💾 数据存储

应用使用浏览器的 `localStorage` 自动保存：
- 当前题目位置
- 答对题数
- 已答题目记录
- 学习开始时间

**注意**：清除浏览器缓存会丢失进度。

## ⌨️ 快捷操作

| 操作 | 说明 |
|------|------|
| 显示答案 | 查看当前题目的答案和解析 |
| 上一题 | 返回前一道题目 |
| 下一题 | 进入下一道题目 |
| 随机出题 | 随机跳转到任意题目 |
| 重置进度 | 清空所有答题记录 |
| 搜索 | 按题目内容或答案搜索 |
| 筛选 | 按题型筛选题目 |

## 📊 统计功能

- **总题数**：显示题库中的总题数
- **答对题数**：已正确回答的题目数
- **准确率**：答对题数 / 已答题数
- **学习时长**：从开始复习到现在的时间
- **题型分布**：各类型题目的数量统计

## 🔄 导出数据

点击"导出数据"按钮可以：
- 下载 JSON 格式的学习统计
- 包含总题数、答对数、准确率等信息
- 方便后续分析和追踪

1. **制定计划**：每天坚持复习一定数量的题目
2. **重点复习**：对错题进行重点复习

## 🐛 常见问题

**Q: 刷新页面后进度会丢失吗？**
A: 不会。应用使用 localStorage 自动保存进度，刷新页面后进度会恢复。

**Q: 可以在多个浏览器间同步进度吗？**
A: 目前不支持。进度只保存在本地浏览器中。

**Q: 如何添加更多题目？**
A: 编辑 `questions-part1.js` 或 `questions-part2.js`，按照现有格式添加题目对象。

**Q: 支持离线使用吗？**
A: 是的。下载所有文件后，可以离线打开 `index.html` 使用。
