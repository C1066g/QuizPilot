# 覆盖层（Overlay）使用指南

## 作用
无需修改源码即可新增/修改题库内容，页面刷新后自动合并应用。

## 支持的来源
- 本地覆盖层（存入浏览器 localStorage）：页面点击“📥 导入覆盖层（本地）”。
- 服务器覆盖层（文件落盘）：上传到 rgzr/custom/（点击“⤴️ 上传覆盖层（到服务器）”）。

## JSON 格式
- 直接数组：题目对象数组
- 或对象包装：
```json
{
  "subject": "exchange",
  "updatedAt": "2025-12-22T10:00:00+08:00",
  "items": [
    { "id": 101, "type": "single", "question": "题干", "options": ["A","B","C","D"], "answer": "B", "answerText": "解析" },
    { "type": "essay", "question": "主观题题干", "answerText": "参考答案" }
  ]
}
```

## 合并规则
- 匹配优先级：id 命中 > 题干文本归一化命中 > 新增
- 字段级覆盖：仅覆盖提供的字段（不提供的不变）
- 新增题自动分配 id

## 操作指南
- 本地导入：点击“📥 导入覆盖层（本地）”并选择 JSON 文件
- 上传到服务器：点击“⤴️ 上传覆盖层（到服务器）”，仅本机可用
- 导出覆盖层：点击“📤 导出覆盖层”
- 清空覆盖层：点击“🧹 清空覆盖层”（仅本地 localStorage）

## 模板
参考：`rgzr/custom/overlay.exchange.template.json`

## 注意事项
- JSON 建议 ≤ 2MB；字段类型需符合题库结构
- 服务器端会列出 rgzr/custom/ 下所有 `.json` 文件作为覆盖层
- 覆盖层仅用于合并显示，不会写回题库源码文件
