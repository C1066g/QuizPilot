【快速启动 - 3步】
================================================================================

步骤 1：双击启动脚本
  - 打开文件夹：d:\桌面\qimofuxi
  - 双击：启动.bat
  - 脚本会自动构建镜像并启动容器

步骤 2：等待启动完成
  - 第一次启动会下载 Python 镜像（约 100MB）
  - 之后会很快
  - 看到"启动完成！"提示即可

步骤 3：访问应用
  - 电脑：http://localhost:8001
  - 手机：http://<你的电脑IP>:8001
  - 例如：http://192.168.1.108:8001

================================================================================
【关键特性】
================================================================================

✅ 后台运行
  - 容器在后台运行
  - 不影响其他应用
  - 电脑重启后自动启动

✅ 与 TrendRadar 隔离
  - 使用不同的端口（8001）
  - 使用独立的 Docker 网络
  - 完全不会相互影响

✅ 资源占用少
  - 内存：10-20MB
  - CPU：几乎不占用
  - 磁盘：约 150MB（包括 Python 镜像）

✅ 手机随时访问
  - 只要电脑开着，手机就能访问
  - 不受电脑睡眠影响
  - 容器会继续运行

================================================================================
【常用命令】
================================================================================

查看容器状态：
  docker-compose ps

查看容器日志：
  docker-compose logs -f ai-review-app

停止容器：
  docker-compose stop

启动容器：
  docker-compose start

重启容器：
  docker-compose restart

删除容器：
  docker-compose down

================================================================================
【故障排查】
================================================================================

问题 1：启动脚本无法运行
  - 确保 Docker Desktop 已安装
  - 确保 Docker Desktop 已启动
  - 右键启动.bat → 以管理员身份运行

问题 2：端口被占用
  - 修改 docker-compose.yml 中的端口
  - 将 "8001:8000" 改为 "8002:8000"
  - 然后重新启动

问题 3：手机无法访问
  - 确认电脑和手机在同一 Wi-Fi
  - 确认防火墙允许 8001 端口
  - 运行 docker-compose ps 确认容器正在运行

================================================================================
【与 TrendRadar 的区别】
================================================================================

TrendRadar（推送项目）：
  - 端口：自定义（通常不暴露）
  - 功能：爬虫 + 推送
  - 资源：中等（定时执行）
  - 网络：独立网络

AI 复习小程序：
  - 端口：8001
  - 功能：静态网站 + 本地存储
  - 资源：极少（只需 HTTP 服务）
  - 网络：独立网络

两个项目完全隔离，不会相互影响！
